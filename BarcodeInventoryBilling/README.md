# Advanced Barcode Inventory, Billing & Invoice Management Android App

Native Android application built with Kotlin, XML layouts, Room Database, CameraX + ML Kit barcode scanning, ZXing barcode generation, Android PdfDocument, and WhatsApp sharing.

## How to Open in Android Studio
1. Open Android Studio (Ladybug / Jellyfish / Hedgehog or newer).
2. Click "Open..." and select this extracted directory.
3. Allow Gradle to sync dependencies.
4. Connect an Android device or start an emulator with Camera support.
5. Click Run (▶) to build and deploy.
